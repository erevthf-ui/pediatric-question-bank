# 儿科刷题档案（Pediatric Question Bank）

本仓库用于托管 Q1–Q5 及后续更新的儿科学习题库网页。

## 网站部署

1. 将完整的 `index.html` 上传到仓库根目录（与本 README 同一层）。
2. 打开 Settings → Pages，选择 Deploy from a branch，分支 main，目录 /(root)，保存。
3. 网站地址：https://erevthf-ui.github.io/pediatric-question-bank/

后续更新：使用新版 `index.html` 替换仓库根目录中的同名文件；GitHub Pages 会重新发布。不要将患者个人身份信息或未获许可公开的材料上传到公开仓库。
